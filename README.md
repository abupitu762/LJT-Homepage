# Junteng Liu

Academic homepage of Junteng Liu, a Ph.D. candidate in the HKUST NLP Group.

- [About](./_pages/about.md): research interests, education, internships, publications, and contact information.
- [Publications](./_pages/publications.html): citations with full author lists.

This site uses [Academic Pages](https://github.com/academicpages/academicpages.github.io). The `_config.yml` file sets the project path to `/LJT-Homepage` and excludes unused template content from the site build.

To preview locally, run `bundle install` and `bundle exec jekyll serve`, then open `http://localhost:4000/LJT-Homepage/`.
