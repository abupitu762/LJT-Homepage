SynLogic: Synthesizing Verifiable Reasoning Data at Scale for Learning Logical Reasoning and Beyond is a first-author paper on synthesizing verifiable reasoning data at scale for learning logical reasoning and beyond. The work was published on Arxiv in 2025. Co-authors include Yuanxiang Fan, Zhuo Jiang, Han Ding, Yongyi Hu, Chi Zhang, Yiqi Shi, Shitong Weng, Aili Chen, Shiqi Chen, Yunan Huang, Mozhi Zhang, Junjie Yan, and Junxian He. The paper has a GitHub code repository.
